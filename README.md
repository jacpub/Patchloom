# Patchloom

![Patchloom's Arcane Weave P and an enchanted loom][patchloom-art]

Patchloom is a World of Warcraft addon download and update manager built from
[Ajour](https://github.com/ajour/ajour). Planned releases target Windows, macOS
and Linux.

Patchloom is in development, with no public release yet. Current WoW
compatibility and provider integrations are still being updated before
everyday use.

## Community

Join [Discussions](https://github.com/jacpub/Patchloom/discussions) for questions
and ideas, or report reproducible bugs in
[Issues](https://github.com/jacpub/Patchloom/issues).

Build and contribution details are in the [developer notes](docs/DEVELOPMENT.md).

## Ajour heritage

Ajour was created by Casper Rogild Storm and its contributors. Patchloom
preserves their source history and attribution. The original project is
[no longer maintained](https://github.com/ajour/ajour/issues/746).

Original artwork credits remain:

- [Rasmus Nielsen](https://rasmusnielsen.dk/) for the Ajour icon.
- [Rune Seir](https://instagram.com/rseir/) for the Ajour banner.
