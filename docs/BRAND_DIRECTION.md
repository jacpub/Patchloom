# Patchloom brand direction

Keep Patchloom visuals on the approved Arcane Weave identity. The selected mark
is a forged, interwoven P with restrained teal arcane accents. New illustrations,
README art and interface assets should extend that identity and the World of
Warcraft addon download/update manager purpose.

The approved brand guide and selected artwork are the source of truth. Use their
verified files when supplied; do not invent replacement marks, proportions,
colors or competing styles from this short description. Small-size adaptations
remain proposals until approved and must not silently replace the selected mark.

Original Ajour illustration can inform the wide README composition and fantasy
setting, but its logo and artwork are not the new Patchloom identity. Preserve
the original files and attribution. Any new asset must have a verified local path
before README integration.

## Public copy

Apply Humanizer to all Patchloom public-facing copy, including README text,
website and store descriptions, announcements, community posts and interface
copy. Keep the language natural, clear and simple. Preserve exact user-approved
wording unless the user requests a change.

The main README introduces the product to players. Keep its purpose, honest
development status, platform targets, community links and Ajour/legal credits
brief. Put clone/build tutorials, test matrices and implementation details in
developer documentation, linked unobtrusively from the README.

Public claims must match verified behavior. Planned platforms, provider support
and safety work must not be described as completed or released prematurely.
New copy and visuals should remain consistent with the approved Patchloom brand.
